# テキスト指定の 3D セグメンテーション（Phase 3）

SAM 3.1 の 2D マスクを、3D 描画時の深度とカメラ姿勢で Gaussian に持ち上げる。設計は [spatialsam_design.md](spatialsam_design.md) §7。

## 方法

1. 学習した 3DGS を、撮影カメラの軌道（3DGS 学習時の評価用視点を除く）で描く。RGB・深度・姿勢を保存する（3D Rendering）。
2. 描画動画にテキストプロンプトで SAM 3.1 をかける（Video Segmentation）。
3. 各 Gaussian の中心を各視点に投影する。描画深度と比べて**見えている視点だけ**で、マスクの内側に写ったかを数える。
   - 見えている条件: 投影した画素の不透明度が 0.5 以上で、中心の深さが描画深度の 1.05 倍以内。
   - 見えた視点のうちマスク内だった割合（信頼度）が 0.5 以上で、見えた視点が 2 つ以上なら、その物体のラベルを付ける。
   - 物体 ID ごとに行う。
4. 評価: 3D のラベルを評価用視点（学習にも持ち上げにも使っていない）に描く。描き方はラベルの α 合成なので、遮蔽も考慮される。これを、同じ視点の**実画像**での SAM の結果と比べる（再投影 IoU）。

深度による逆投影 `p_world = T_world←cam [z K⁻¹(u,v,1)ᵀ; 1]` も `spatial/mask_lifting.py` の `backproject` に実装した（点群へのラベル付け用）。

## 結果（Mip-NeRF 360 bonsai、3DGS は 7000 step・Gaussian 100 万個）

- 持ち上げに使った視点: 学習用の 255 視点から 3 枚おきに 85 視点（780x520）
- 評価用視点: 37 視点（実画像）

| プロンプト | ラベルした Gaussian | 平均信頼度 | 再投影 IoU（平均） | 中央値 | 持ち上げ時間 |
|---|---:|---:|---:|---:|---:|
| bonsai | 190,588（1 物体） | 0.93 | 0.884（実画像で検出された視点では 0.908） | 0.908 | 9.7 秒 |
| table | 346,996（5 物体） | 0.97（主な机） | 0.927 | 0.957 | 10.9 秒 |

- **bonsai の平均を下げたのは視点 0（IoU 0）だけ。** 実画像の SAM がこの視点で bonsai を見落としていた（#16 で確認済み）。3D 側は正しく写しているので、評価から外して別に数えた（`reference_empty_views`）。
- **しきい値（min_ratio）への依存は小さい。** 0.3 / 0.5 / 0.7 で再投影 IoU は 0.905 / 0.908 / 0.903。
- **table は複数の机を別の物体 ID として持ち上げられる。** 中央の机（34 万個）のほか、奥の机なども別 ID になった。
- 描画で一度も見えなかった Gaussian は 26,209 個（2.6%）。主に撮影範囲の外にある。

再現:

```bash
# 3D Rendering で撮影カメラ軌道（評価用視点を除く = 8、stride 3）を描画 → Video Segmentation で「bonsai」
uv run python scripts/lift_masks.py --experiment <experiment_id> --compare <comparison_id>
```
